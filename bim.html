BIM product system for manholes

BIM product system for manholes

From a design order to native-rebar models and issued sheets

Manhole drawings were drafted case by case, so the same product could appear in different forms and every new size meant new drafting.

How it works

The Designer workbook takes the order; a C# rule engine resolves every piece; the Revit add-in builds families, native rebar, views and sheets and exports PDF, DWG, IFC and RVT with BBS, BOM and take-off. An automated check holds each sheet to the drafting standard.

What I built

  • A Revit 2027 add-in driven by a C# rule engine: families, native rebar, openings, steps, views and sheets, exported to PDF, DWG, IFC and RVT with BBS, BOM and take-off.
  • One master data set feeds every sheet; an automated check holds each sheet to the drafting standard.
  • The same pipeline issues the RC pipe and jacking-pipe drawing sets.
  • Released as v1.0 in October 2026 with 1,000+ automated .NET tests.
